# 🤝 Contributing to LocalBiz AI WhatsApp Agent

First off, thank you for considering contributing! This project aims to help local businesses automate their customer support for free.

## 📌 Code of Conduct

By participating, you agree to be respectful and constructive. Help us build something useful for small business owners.

## 🚀 How Can I Contribute?

### Reporting Bugs

If you find a bug, please open an issue on GitHub and include:
- A clear title and description.
- Steps to reproduce the problem.
- Expected vs actual behavior.
- Screenshots or logs (if relevant).
- Your environment (OS, Python version, Docker version).

### Suggesting Features

We welcome feature requests! Open an issue with the label `enhancement`. Examples:
- Support for multiple languages.
- Integration with Google Calendar for appointments.
- Web dashboard for conversation history.

### Pull Requests

1. **Fork** the repository.
2. **Clone** your fork:
